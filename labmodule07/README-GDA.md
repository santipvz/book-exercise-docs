# Gateway Device Application (Connected Devices)

## Lab Module 07

Be sure to implement all the PIOT-GDA-* issues (requirements) listed.

### Description

La implementación del Gateway Device Application (GDA) se centra en la gestión y procesamiento de datos de sensores y actuadores. El sistema actúa como un intermediario entre los dispositivos restringidos (CDA) y los servicios en la nube, proporcionando una capa de abstracción y procesamiento de datos.
